## Selected work

### [StreamHub](https://github.com/DennyM55/streamhub) · active build

A Java media-platform demonstration with a separate catalogue service, PostgreSQL persistence, Redis caching, Kafka watch events, and a React frontend. It covers authentication, favourites, watch history, playback progress, resilient service calls, and an outbox-based event flow.

`Java 21` `Spring Boot` `PostgreSQL` `Redis` `Kafka` `React`

### [Redis Sliding-Window Rate Limiter](https://github.com/DennyM55/rate-limiter)

A focused distributed-systems project that keeps per-user request history in Redis and uses an atomic Lua script for rolling-window admission. It returns explicit quota headers and documents its fail-open behaviour when Redis is unavailable.

`Java 21` `Spring Boot` `Redis` `Lua` `REST`

### [BrieflyAI](https://github.com/DennyM55/brieflyai)

A full-stack notes application that persists a note before generating its summary asynchronously. The backend uses Spring AI with OpenAI as the primary provider, local Ollama fallback, and a circuit breaker around provider failures.

`Java 21` `Spring Boot` `Spring AI` `PostgreSQL` `React` `Docker Compose`

### [AI Interview Architect](https://github.com/DennyM55/ai-interview-architect)

An AI engineering project for resume analysis, persistent interview-prep chat, content generation, and document Q&A. It explores provider abstraction, lightweight local RAG, deterministic tests, Docker packaging, and CI.

`Python` `Streamlit` `RAG` `Ollama` `Gemini` `GitHub Actions`
